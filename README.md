# Telegram AI-ассистент

Отдельный Netlify-проект. Делает несколько вещей:
- каждое утро в 09:00 (Новосибирск) шлёт в группу дайджест новостей ИИ + совет по твоему приложению
- отвечает в группе, когда его упомянули (`@имя_бота вопрос`) или ответили на его сообщение
- по команде `/app` присылает кнопку для открытия Mini App прямо в группе
- 3 раза в день (8:30, 14:00, 18:00 Frankfurt) присылает статус по недельному плану из Google Sheets

## 1. Создать бота

1. В Telegram напиши `@BotFather` → `/newbot`, задай имя и username (например `artem_ai_assistant_bot`).
2. Сохрани токен, который он выдаст — это `TELEGRAM_BOT_TOKEN`.
3. Настраивать privacy mode не нужно — по умолчанию бот в группах и так получает только команды, упоминания себя и ответы на свои сообщения. Это ровно то поведение, которое нужно.

## 2. Создать группу и добавить бота

1. Создай в Telegram группу (это и есть твоё хранилище — промты, инструкции, ссылки просто скидывай туда, ищутся через встроенный поиск Telegram).
2. Добавь туда бота как обычного участника.
3. Узнать `chat_id` группы: временно добавь в группу `@RawDataBot` (или `@getidsbot`), он пришлёт `chat_id` группы (число со знаком минус). Это `TELEGRAM_CHAT_ID`. После этого `@RawDataBot` можно удалить из группы.

## 3. Задеплоить на Netlify

1. Залей эту папку в отдельный git-репозиторий (или используй `netlify deploy` из CLI прямо из папки).
2. На netlify.com → New site → подключи репозиторий (или `netlify init` из CLI).
3. В настройках сайта → Environment variables добавь:
   - `TELEGRAM_BOT_TOKEN` — токен от BotFather
   - `TELEGRAM_CHAT_ID` — id группы (с минусом)
   - `TELEGRAM_BOT_USERNAME` — username бота без `@`
   - `TELEGRAM_WEBHOOK_SECRET` — придумай любую случайную строку
   - `DEEPSEEK_API_KEY` — твой ключ DeepSeek
4. Задеплой (`netlify deploy --prod` или через git push — Netlify сам поставит зависимости из `package.json`).

## 4. Подключить webhook

После деплоя у тебя будет адрес вида `https://твой-сайт.netlify.app`. Выполни один раз в браузере (подставь свои значения):

```
https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/setWebhook?url=https://твой-сайт.netlify.app/.netlify/functions/telegram-webhook&secret_token=<TELEGRAM_WEBHOOK_SECRET>
```

Должен прийти ответ `{"ok":true,...}`.

## 5. Проверить

- Напиши в группе `@имя_бота привет` — должен ответить.
- Дайджест сработает сам по расписанию (см. `netlify.toml`, cron в UTC). Проверить руками, не дожидаясь утра, можно открыв в браузере:
  `https://твой-сайт.netlify.app/.netlify/functions/morning-digest`

## Живой контекст из приложения (опционально)

Дайджест может знать твой актуальный прогресс (текущий день, %, стрик, последние заметки)
вместо статичного описания проекта. Это отдельный слой поверх всего описанного выше:

1. В настройках сайта бота на Netlify добавь env-переменную `SNAPSHOT_WRITE_SECRET` — придумай
   ещё одну случайную строку (можно ту же, что и `TELEGRAM_WEBHOOK_SECRET`, а можно отдельную).
2. Опционально задай `APP_ORIGIN` — домен, с которого задеплоено приложение (`index.html`),
   например `https://твоё-приложение.netlify.app`. Без неё CORS открыт для всех (`*`) — не критично
   для личного use-case, но если хочешь строже, укажи домен явно.
3. В самом `index.html` приложения найди константы `SNAPSHOT_URL` и `SNAPSHOT_SECRET` (в начале
   скрипта, рядом с `Store`) и заполни их:
   - `SNAPSHOT_URL` = `https://твой-бот-сайт.netlify.app/.netlify/functions/snapshot-write`
   - `SNAPSHOT_SECRET` = та же строка, что в `SNAPSHOT_WRITE_SECRET`
4. Задеплой обновлённый `index.html`. Дальше приложение само, спустя ~20 сек после любого
   изменения прогресса, тихо шлёт снепшот боту. Если бот недоступен или поля пустые — ничего
   не ломается, приложение просто продолжает работать как обычно.

Без этого шага дайджест продолжит работать на статичном описании проекта — просто советы
будут общими, а не привязанными к конкретному дню.

⚠️ Секрет лежит в клиентском JS открытого приложения — это не настоящая защита (любой может
посмотреть исходник страницы), а просто фильтр от случайного мусора. Не используй этот механизм
для чего-то чувствительнее прогресса обучения.

## Что можно донастроить

- **Список источников новостей** — массив `FEEDS` в `netlify/functions/morning-digest.js`, RSS без ключей.
- **Время дайджеста** — `schedule` в `netlify.toml` (в UTC; сейчас `0 2 * * *` = 09:00 Новосибирск, часовой пояс без перевода времени — менять не придётся).
- **Тон ответов бота** — `SYSTEM_PROMPT` в `telegram-webhook.js`.

## 6. Кнопка Mini App в группе (`/app`)

1. В BotFather: `/mybots` → выбери бота → **Bot Settings** → **Configure Mini App** (или `/newapp`, если такого пункта нет) → задай короткое имя, например `learn`, и URL — адрес, на котором задеплоено твоё приложение (`index.html`).
2. В Environment variables на Netlify (для этого бот-проекта) добавь:
   - `TELEGRAM_MINIAPP_SHORTNAME` = короткое имя, которое задал в шаге 1 (например `learn`)
3. Задеплой. В группе напиши `/app` — бот пришлёт кнопку, по которой открывается Mini App. Сообщение с кнопкой можно закрепить в группе, чтобы не искать команду каждый раз.

## 7. Статус по недельному плану (Google Sheets)

Бот 3 раза в день читает вкладку текущей недели в твоей таблице и присылает, что сделано и что осталось на сегодня.

1. В [Google Cloud Console](https://console.cloud.google.com/) создай проект (или используй существующий) → **APIs & Services** → **Library** → включи **Google Sheets API**.
2. **APIs & Services** → **Credentials** → **Create credentials** → **API key**. Рекомендуется ограничить ключ (Restrict key → API restrictions → только Google Sheets API).
3. Таблица должна быть доступна по ссылке на чтение (уже так и есть — открывается без входа).
4. В Environment variables на Netlify добавь:
   - `GOOGLE_SHEET_ID` — id таблицы из её URL (часть между `/d/` и `/edit`)
   - `GOOGLE_SHEETS_API_KEY` — ключ из шага 2
5. Задеплой. Расписание — `weekly-progress-morning/noon/evening` в `netlify.toml` (8:30 / 14:00 / 18:00 Frankfurt).

Логика ищет вкладку по названию недели (диапазон дат вида `04.08 - 10.08`) и внутри неё — блок сегодняшнего дня по дате в заголовке колонки. Если структура вкладки отличается от ожидаемой, бот пришлёт предупреждение вместо статуса — тогда нужно будет чуть поправить `_weekly-progress-lib.js` под реальные координаты.
